## 🚀 Quick Reference

### Start Development
```bash
# Backend
cd server
npm install
npm run dev              # Runs on :4000

# Frontend
cd client
npm install
npm run dev             # Runs on :5173
```

### Run Tests
```bash
# Backend tests
cd server
npm test                # All tests

# Frontend tests
cd client
npm run test -- --run   # Single run
npm run test:coverage   # With coverage
```

### Build for Production
```bash
# Frontend
cd client
npm run build           # Creates dist/

# Backend
cd server
npm run build          # Creates build/
```
